# 上传一首音乐

直接把一首 `.mp3`、`.ogg`、`.wav`、`.m4a` 或 `.flac` 文件上传到本目录即可。文件名（去掉扩展名）就是曲名，不需要编辑清单或覆盖游戏脚本。

[打开本目录的 GitHub 上传页](https://github.com/zqshi0911/northbound-rail-race/upload/main/docs/content/music)

提交后，在游戏的线路选择页点“检查更新”，再打开“音乐与沿途语音”选择新曲目。浏览器不支持某种音频编码时，可将文件转为 MP3 或 OGG 后上传；仅改后缀不会转码。

开发目录为 `public/content/music/`，GitHub Pages 的发布目录为 `docs/content/music/`。本 README 不会作为音乐读取。
