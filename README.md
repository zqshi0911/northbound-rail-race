# 一路向北 · 铁路竞速与运行图驾驶

公开游玩：https://zqshi0911.github.io/northbound-rail-race/

当前收录37条线路／跨线路径、74个方向、407个公开资料核验的车次区段任务。任务数不等于独立列车数。提供竞速、标准／进阶按图行车、停车练习、双向短交路与真实枢纽跨线。

## 更新与上传

把“网页上传版”中的 **docs文件夹和README.md** 拖入 [GitHub覆盖上传页](https://github.com/zqshi0911/northbound-rail-race/upload/main)，保留docs这一层目录，提交更改。不要把ZIP直接上传；ZIP需要先解压。Pages继续使用main分支的/docs目录，提交后等待仓库Actions中的Pages部署成功。

游戏脚本和样式带内容版本号，新提交部署成功后刷新即可；若浏览器仍显示旧菜单，可强制刷新或清除此站点缓存。仅复制文件到本地不会自动更新GitHub网站。

本地启动：在D:\休闲\列车竞速双击“启动本地.cmd”。也可直接打开“网页上传版/docs/index.html”，离线游戏可用。独立源码位于“GitHub发布版”，执行npm install、npm run build生成docs；主项目用node scripts/export-github-pages.mjs重新导出。主项目使用D盘自带Node运行时。

## 操作与玩法

按住空格、↑、W或“牵引”前进，松开制动；P/Esc暂停，R重开，V切换司机／追踪视角，M展开地图。按图行车可用1—6快速切1/5/15/30/60/120倍，[与]逐档，反引号在1倍与原倍率间切换。近站切1倍精确停车；停车练习从标前5公里、初速200 km/h开始。

竞速不限速度，根据曲率计算游戏侧翻风险，复轨时间计入成绩。赛后可查看每站通过时间、速度与风险弯道的入弯／弯心／出弯速度、最大负荷和事故。中国双线左行，车站有站房、雨棚和站名牌；风景是沿线地域风貌的三维艺术化重建。

标准与进阶共读一份37,146条双向分段速度记录及运营封顶；标准提供速度辅助，进阶手动控速。未知源标签区间明确显示“游戏模型”，不冒称官方临时限速。停车精度55%＋时刻匹配45%，违规按所选任务里程归一；超过适用限速10 km/h后才计超速罚分，此为本作容差。长无停稳定路段大幅反复变速另计平稳性，正常近站、枢纽和弯道降速免计。进阶提供2/5/10模拟分钟临时巡航，遇降限需手动接管。

## 音乐、语音与在线榜

在“音乐与沿途语音”中可选两首原创怀旧铁路广播风格器乐、音量及沿途讲解，默认关闭。器乐不是沈阳铁路局原录音。讲解使用设备的中文语音，语音不可用时仍显示文字。

本机游戏与成绩无需登录。在线榜通过独立托管的Worker＋D1接口保存，GitHub Pages本身不提供数据库。匿名昵称和本机设备标识用于提交；目前没有账号系统。竞速榜由服务器按相同规则重放校验，按线路／方向／交路／辅助／规则版本分榜，每设备取最佳成绩。重放通过不表示真人操作认证。按图成绩暂为未核验的玩家申报榜，单独标注与展示。

默认接口：https://northbound-rail-race-r71.bluishkite2.chatgpt.site/api/leaderboard 。若该域名在访问者网络受拦截，在线榜可能不可用，游戏和本机纪录继续正常使用。可在组件配置VITE_LEADERBOARD_URL迁到其他同等接口；静态导出也可修改HOSTED_API后重建。后台实现及迁移保存在主项目app/api/leaderboard、lib/rail-leaderboard.ts、db及drizzle目录，托管部署自动执行迁移。
