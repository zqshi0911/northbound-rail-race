# 一路向北 · 铁路驾驶
灵感来源于https://why002.github.io/1462-simulator/
竞速与按运行图驾驶游戏：六条基础铁路、五条跨线径路、22个方向、17个核验车次任务。

GitHub Pages发布完成后的游玩地址：https://zqshi0911.github.io/northbound-rail-race/

按住空格、↑、W或牵引前进，松开制动；P/Esc暂停，R重开。近站可切1×精确停车。进阶模式提供细段限速、超速扣分、弯道侧翻风险与临时巡航。

本版本无需账号或后台，成绩和导入资料保存在玩家浏览器。线路及基础设施速度采用OSM数据，缺口明确标为游戏模型。标准车次使用2026年11月7日公开核验快照；未公开的通过时刻不计分。沿线风景为艺术化三维重建。
