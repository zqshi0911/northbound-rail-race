# 一路向北 · 铁路竞速与运行图驾驶

公开游玩：https://zqshi0911.github.io/northbound-rail-race/

本版包含21条线路/径路、42个方向与345个公开核验的车次区段任务。提供全程与短交路；北京西—郑州东等区间可独立游玩并保存纪录。车次按已核验的标杆/常规等级及任务停站型展示，包含大站快车、少停站、区间全停与直达，可按难度或停站数排列。线路和车次均有五级难度标志；进阶规则单独评估。新增秦沈、长春/哈西经津秦京沪至上海直通及16项真实时刻任务；选线页有主要弯道速度提示和可点选的限速线路图。保留京沈G36xx常规与350标杆分类。

无需账号、API密钥或后台服务器。成绩与导入资料保存在当前浏览器。可直接双击docs/index.html，或把docs部署到GitHub Pages。按住空格、↑、W或牵引前进，松开制动；P/Esc暂停，R重开。按1—6快速切1/5/15/30/60/120×，[与]逐档，反引号恢复原倍率，V切换司机视角。新增标前5km、初速200km/h停车练习；手机竖屏支持展开地图。标准/进阶共用完整细段限速；distance-v2违规扣分按任务里程归一，超速从限速+10km/h以上计罚（游戏容差），长无停稳定段大幅反复变速另计平稳性。进阶提供弯道风险与临时巡航。

## 更新与部署

GitHub Settings → Pages → Deploy from a branch → main → /docs → Save。替换已有docs文件后提交，等待Pages部署成功。修改源码后执行npm install、npm run build。

## 资料口径

新增任务采用CNRail lastUpdate=2026-11的公开到发时刻，并与公开车次表互核，保留原始车次/区段及来源。它是公开资料核验快照，未接入12306实时运行图；不编造未公开的通过时刻。站站停只用于至少三个相邻沿线站全部办理停站的真实区段；两站径路标两站直达，未核实全停的线路保留多站停靠。跨线父径路里的短任务明确标注截取范围，不冒称整条径路图定直通。完整证据见资料说明。

线路及速度标签来自OpenStreetMap，数据库按ODbL 1.0，保留© OpenStreetMap contributors。OSM是基础设施速度标签，缺口显示游戏模型，地下直径线模型不冒称官方细限速。静态JS仅压缩运行必需的数据，docs中的下载数据保留完整来源证据。依赖许可保留在game.js.LEGAL.txt。除明确的第三方许可外，不另授源码再许可权。
